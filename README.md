--Возможности SSL-бота--

1) Выгрузка SSL-сертификата по ссылке

Пользователь присылает URL (http:// или https://).
-Бот подключается к указанному хосту и получает действующий SSL-сертификат.
-Сертификат возвращается в PEM-формате.

2)Отображение информации о сроке действия
-Извлекается период действия сертификата (NotBefore – NotAfter).
-Пользователь получает читаемое сообщение: «Срок действия: с … по …».

3)Форматированный вывод для Telegram
-Используется MarkdownV2 для аккуратного отображения сертификата и сроков.
-Специальные символы экранируются, чтобы текст не ломал форматирование.

4)Обработка ошибок подключения
- Логируется и отправляется пользователю ошибка при таймауте или невозможности соединения.
- Если сайт не выдаёт сертификат или недоступен — бот сообщает об этом.

5) Логирование событий
- Логирование в единый файл с ротацией по дням.
- Дополнительный вывод в консоль для отладки.

Фиксируется:
-Запуск бота.
-Запросы пользователей (ID, username, имя).
-Успешная выдача сертификата.
-Ошибки при обработке запросов.

6) Поддержка нескольких пользователей
-Любой пользователь Telegram может прислать ссылку и получить результат.
-Сохраняется информация о пользователях в логах (id, username, name).

7) Удобные команды
/start и /help возвращают приветственное сообщение с инструкцией.

# 1. Кастомный форматтер логов с временными зонами
class ZoneFormatter(logging.Formatter):
    def __init__(self, fmt=None, datefmt=None, tz="Asia/Yekaterinburg"):
        self.tz = ZoneInfo(tz)
    
    def formatTime(self, record, datefmt=None):
        dt = datetime.fromtimestamp(record.created, tz=self.tz)
        return dt.strftime(datefmt)

# 2. Безопасное извлечение сертификатов
def get_certificate(hostname, port=443):
    context = ssl.create_default_context()
    context.check_hostname = False
    context.verify_mode = ssl.CERT_NONE
    with socket.create_connection((hostname, port), timeout=5) as sock:
        with context.wrap_socket(sock, server_hostname=hostname) as ssock:
            return ssock.getpeercert(binary_form=True)

# 3. Экранирование Markdown для безопасности
def escape_markdown(text: str) -> str:
    escape_chars = r'_*[]()~>#+-=|{}.!'
    return re.sub(f"([{re.escape(escape_chars)}])", r"\\\1", text)
